    Shape editor
    
        
    Changes save directly to the watched file.
    

        
        

        
    
          Select a point
          Drag an anchor to move it
          
    
            
            
          
    
        
    

        
    
          Handles stay linked by default. Hold Alt to move one,
          Shift for 45°, or press ⇧C to create an equal pair.
          Shift-click points to select several, or press
          Ctrl/⌘A to select the whole shape. Drag or use arrow keys to move the
          selection; hold Shift for 10 units or Alt for 0.1.
          Alignment guides snap anchors. Scroll to pan;
          Ctrl/⌘-scroll zooms. Select exactly what you want to remove, then press
          Delete. Use Ctrl/⌘Z to undo.
