# Strøk

Strøk is a scriptable vector-design toolkit. Its plain-text `.strok` files are
editable by people and agents and render to SVG or PNG.

## Install

```sh
brew install adhvfed/tap/strok
```

## Start

```sh
strok agent-intro
strok guide illustration
```
