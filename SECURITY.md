# Security policy

Strøk is alpha software. Only the latest revision on the `main` branch receives
security fixes.

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository and include:

- the affected command or file format;
- the smallest reproduction you can share;
- the expected and observed behavior;
- any known impact.

Avoid including credentials, private design files, or unrelated machine
details. You should receive an initial response within seven days.
